# Founder Review Protocol

For each BB, run one deliberate review cycle.

1. Read it without editing.
2. State the single idea in your own words.
3. Use every interaction on a phone and a desktop.
4. Record confusing wording, missing prerequisites and pacing problems.
5. Ask AI to propose narrowly scoped amendments.
6. Read the amended BB from the beginning.
7. Mark it `APPROVED` only when the idea, wording and interaction all work.

Recommended session limit: one BB. Stop after a decision or a clearly recorded amendment request.

AI must not silently alter already approved learner-facing text. Any proposed change returns that BB to `AMENDMENTS_REQUIRED` until the founder reviews it again.
